## Política de segurança

1. Não usar links `releases/latest` nem `releases/latest/download` para distribuir o APK.
2. Links públicos de download devem apontar **somente** para a release fixa `android-v1.0.28` e o arquivo `Rodrinox-Pro-Android.apk`.
3. GitHub Actions pode gerar artefatos de teste, mas não publicar automaticamente uma nova release nem alterar a indicação de versão oficial.
4. Para uma futura versão, manter testes separados; obter aprovação expressa e atualizar este registro, o hash e os links em mudança controlada.
5. Não excluir tags ou releases históricas sem autorização específica. Arquivar aqui não impede download direto das releases antigas por quem possua os links.
